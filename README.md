**GameStack** es una aplicación web desarrollada con **Spring Boot** y **Bootstrap** bajo la arquitectura **MVC** (Modelo-Vista-Controlador), diseñada para la gestión y exploración de un catálogo de videojuegos.

---

## 🚀 Tecnologías Utilizadas

* **Backend:** Java, Spring Boot (Spring MVC, Spring Data JPA)
* **Frontend:** HTML5, Thymeleaf, Bootstrap 5
* **Gestor de dependencias:** Maven
